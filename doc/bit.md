# Bit counting methods

The following methods are defined in the built-in `bit` class:
- `bit.add(x, y, carry)`
- `bit.div(hi, lo, y)`
- `bit.len(num)`
- `bit.lenabs(num)`
- `bit.mul(x, y)`
- `bit.ones(num)`
- `bit.rem(hi, lo, y)`
- `bit.reverseBits(num)`
- `bit.reverseBytes(num)`
- `bit.rotateLeft(x, k)`
- `bit.str(num)`
- `bit.strAllBits(num)`
- `bit.sub(x, y, borrow)`
- `bit.zerosLead(num)`
- `bit.zerosTrail(num)`
